Chat commands

start Begin the course from Lesson 1. Use on first run.
continue Resume the current open quick-check. The bot re-states the question and waits for your answer.
lesson 4 Jump directly to Lesson 4 — triggers a full lesson intro (mental model → example → quick-check). Also accepts go to lesson 4, jump to lesson 4, skip to lesson 4, lesson 4 please. Message must be short (≤ 60 characters).
any question Ask anything off-topic — your own data, a specific function, a workflow question. The bot answers fully, then returns with Back to Lesson N — to pick up where you left off.
The course tracks 15 lessons in order, but you can jump freely. Off-topic questions are always welcome — they won't break the lesson flow.

Lesson navigation

Sidebar dropdown Select any lesson from the Jump to lesson dropdown and click Go to lesson. Same result as typing "lesson N" in chat.
✓ Mark lesson complete Manually mark the current lesson done if the bot didn't auto-detect it. The bot auto-detects completion when it emits a ✅ signal at the end of your correct answer — use the button if you answered correctly but the signal was missed.
Progress tab Visual overview of all 15 lessons — doughnut chart (% done), bar chart (per-lesson status: green = done, blue = current, grey = pending), and a full lesson list with descriptions.

Model & API key

Auto-detect Provider is resolved from the key you paste: sk-ant-… → Claude, sk-… → OpenAI, no key → Ollama (local). The badge in the context bar shows auto → claude-sonnet-4-6 so you always see what's actually running.
Claude / OpenAI Select the provider explicitly, paste your API key, and optionally type a specific model name (e.g. claude-opus-4-8, gpt-4o). Leave the model field blank to use the default for that provider.
Ollama (local) No API key needed. Requires Ollama installed and running locally. Default model: llama3.2. Click ↺ next to the model field to fetch your locally installed models. Pull new models with ollama pull modelname in a terminal.
Remember key Saves the API key to user_data/settings.json on this machine. Unchecking removes it. Model choice and model name always save regardless.
Default models: Claude → claude-sonnet-4-6  ·  OpenAI → gpt-4o-mini  ·  Ollama → llama3.2

Context bar (above the input)

% fill bar Estimated tokens used ÷ model context window. Green → safe. Amber → getting full. Red → compact soon or responses may degrade. Ollama default: 4 096 tokens (fills fast). Claude: 200 000. GPT-4o: 128 000.
⊙ Compact Asks the LLM to write a ~200-word summary of the session (lessons covered, concepts understood, mistakes, where you left off). Replaces the full history with that note. New messages continue from the summary. Nothing is lost — progress and profile are kept.
✕ Clear Wipes the chat history entirely. Lesson progress and profile are not affected. Use when you want a completely fresh conversation.
Compact is the preferred option when the bar turns red — it preserves context. Clear is a hard reset of the conversation only.

What saves automatically

Chat history Saved after every message (up to 80 messages). Reloads on next startup with a ── session resumed ── divider. Lesson progress Which lessons are complete and the current lesson. Persists across restarts. Profile Your language background and use-case. Saved when you click Save profile. Model & provider Provider choice and model name always save. API key only saves if Remember key is checked.
All data lives in user_data/ next to the app. Delete that folder to start completely fresh.
